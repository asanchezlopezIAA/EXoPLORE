EXoPLORE
========

**EXoPLORE** is a Python framework for simulating high-resolution transmission
and emission spectroscopy observations of exoplanet atmospheres and for
retrieving atmospheric parameters using Bayesian inference. It is designed for
feasibility studies, pipeline development, and retrieval validation for
current and next-generation ground-based spectrographs.

.. admonition:: Note
   :class: danger

   This is an early public release. The documentation is actively being
   expanded; feedback and suggestions are welcome via the
   `GitHub issue tracker <https://github.com/asanchezlopezIAA/EXoPLORE/issues>`_.
